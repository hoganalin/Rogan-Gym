# R Fitness 驗證紀錄 — 2026-10-01

## 驗證方式

使用 `npm run verify:clean`，將目前原始碼複製到全新的暫存目錄，排除環境密鑰、既有依賴與建置產物。根目錄、後端、前端各自依 lockfile 執行 `npm ci`，搭配空白 PostgreSQL 16.4 容器、自動分配的 API 與前端埠。測試帳號、方案、技能與課程由測試自行建立。

環境為 Windows、Node.js 22.19.0、Chromium，API 與資料庫連線時區為 Asia/Taipei。這是依賴及資料庫隔離的本機驗證，未包含雲端部署或 GitHub Actions 遠端執行。

## 修正內容

- 根目錄 Jest 僅收集後端合約測試，前端瀏覽器測試由 Playwright 執行。
- PostgreSQL session 使用 Node 的時區，避免 timestamp 預設建立時間在月初或年初落入不同報表期間。另驗證跨月與跨年時間往返；既有資料未轉換。
- 營收依有效報名筆數計算，參與人數另依會員去重；加入同一會員報名兩堂課的回歸案例。
- 瀏覽器測試支援獨立 API 位址，會員流程自行建立堂數方案，照片預覽測試直接操作教練頁面。
- 測試依 catalog、accounts、coach-management、discovery、bookings、revenue 分類；API 文件與 CI 使用相同功能命名。
